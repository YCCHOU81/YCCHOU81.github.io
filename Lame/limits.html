Step 3

Compute the approach

Choose a preset, then compute. Deeper runs keep checked points.

Custom depth & sampling

Start with the recommended comparison. Increasing only depth keeps matching checked points; changing the path or sampling starts a new trace. Internal continuation and precision checks remain adaptive at every sampling setting. More samples make the curve smoother; greater depth tests a later part of the approach.

Research depths 10⁻⁴⁰ and 10⁻⁸⁰ are optional cancellation and slow-convergence tests. They are usually unnecessary for a first comparison and can reach the time budget. A deeper requested ε is not a promise of more correct digits.

Solver details

Computation help

ε = 1 is your chosen starting point. Smaller ε follows the straight segment toward the target. The boundary itself, ε = 0, is never numerically evaluated.

Read the last three real parts below the plots; increase depth if they have not settled. Changing the handles does not launch a solve. Each run has a 45-second budget. A time stop keeps checked points; Continue calculation reuses a checkpoint when available. A failed precision or branch check is explained and never bypassed.

How to interpret the numerical checks

These coordinates come from computed roots. An ellipsis truncates the stored decimal; it does not mean the real part equals the limit. Distance to a reference is not numerical error. The numerical check compares working precisions in the displayed coordinate and is not a certified bound. Hover a real part or use the full data below for all stored digits.
